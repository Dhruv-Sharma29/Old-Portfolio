## 💻 Getting Started

Clone the repository:

``` bash
git clone <your-repository-url>
cd <your-project-folder>
```

Install dependencies if required:

``` bash
npm install
```

Start the development server:

``` bash
npm run dev
```

Then open the local URL shown in your terminal.
