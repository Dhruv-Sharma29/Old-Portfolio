# Old Portfolio

Historical static portfolio with a terminal-style interface. This repository preserves an earlier design and should not be treated as the current project catalog. Some project entries are placeholders, and the old model-count and accuracy claims are not backed by evaluation artifacts in this repository.

The source consists of `index.html`, `styles.css`, and `script.js`; there is no npm project or build step.

## Preview locally

```sh
git clone https://github.com/Dhruv-Sharma29/Old-Portfolio.git
cd Old-Portfolio
python3 -m http.server 8000 --bind 127.0.0.1
```

Open `http://localhost:8000`. Review each linked project's own README and validation results for its current status.
